# 📝 SNotepad

A simple, clean and lightweight **Notepad application** built with **C# Windows Forms**. SNotepad provides all essential text editing features in a minimal and easy-to-use interface.

## ✨ Features

- 📄 **New File** — Create a new blank document
- 📂 **Open File** — Open existing `.txt` files
- 💾 **Save File** — Save your work instantly
- 💾 **Save As** — Save file with a new name or location
- ✂️ **Cut, Copy, Paste** — Standard text editing operations
- 🔄 **Undo / Redo** — Undo and redo your changes
- 🔍 **Find & Replace** — Search and replace text
- 🖨️ **Print** — Print your document
- 🔠 **Font Settings** — Change font style and size
- 🌙 **Word Wrap** — Toggle word wrap on/off

## ▶️ How to Run

**Option 1 — Using Visual Studio:**
1. Clone or download this repository
2. Open `SNotepad.csproj` in Visual Studio
3. Press **F5** or click **Run**

**Option 2 — Using .exe file:**
1. Go to `bin/Debug/` folder
2. Double click `SNotepad.exe`
